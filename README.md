QR Code Generator:

A simple QR Code Generator built using HTML, CSS and some JavaScript.

Features:

- Enter a Text or URL and a QR Code will be generated for the text or the URL entered.
- Save the QR code as an image and add it to your slides, flyer or any material you have.
  

Description:

This project allows users to create a QR code easily for any URL or text and save it as an image so they can use it whenever they need.. 

Technologies Used:

- HTML
- CSS
- JavaScript
- QR Code API by: https://goqr.me/api/

Simple and easy to use.
